# Auto Get and Copy "query_id=" Telegram

A small automation that gets and copies the `query_id=` value from Telegram, the parameter Telegram web apps hand to bots and mini apps when they launch.

## Status

This repository currently contains only `log.md`, an automatically updated log file. The tool's code has not been published in this repository yet, so there is nothing to install or run from here at the moment. This README exists so the repository explains itself; it will be expanded when the code is published.
